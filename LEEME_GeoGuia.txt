GEOGUIA - VERSION CON PALETA MARRON

ARCHIVOS
- index.html: pantalla publica para el formulario y hasta 3 posibles minerales.
- admin.html: pantalla separada para administrar el catálogo y los campos.
- minerales.js: catálogo inicial.
- README.md: descripción e instrucciones del proyecto.

USO LOCAL
1. Mantén los archivos principales en la misma carpeta.
2. Abre index.html en el navegador.
3. Para administrar, abre admin.html desde el mismo navegador.

ACTUALIZAR TU REPOSITORIO LOCAL Y HACER GIT PUSH
1. Copia/reemplaza estos archivos en la raíz de tu repositorio local.
2. Abre una terminal dentro de la carpeta del repositorio y ejecuta:

  git status
  git add index.html admin.html minerales.js README.md LEEME_GeoGuia.txt
  git commit -m "Actualiza GeoGuía con paleta marrón"
  git push origin main

Si tu rama principal tiene otro nombre, reemplaza main por el nombre correcto.

LOGO
El logo actual es un símbolo geométrico temporal en líneas claras sobre fondo marrón. Cuando tengas el logo definitivo, se puede sustituir y adaptar para que combine con la paleta.

NOTAS
- Los resultados son orientativos.
- El administrador guarda los cambios en el navegador local; todavía no usa autenticación ni base de datos compartida.
